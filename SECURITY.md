# Security Policy

## Reporting vulnerabilities

Please **do not** open public issues for security vulnerabilities.

Report privately instead:

- Open a [private security advisory](https://github.com/Alastair-Jiang/cognitive-os/security/advisories/new), or
- Email the repository maintainers.

You should receive a reply within 7 days. Please include:

- Affected version / commit
- Reproduction steps
- Impact description

## Supported versions

| Version | Supported |
|---------|-----------|
| Latest | ✅ |
| Older | ❌ (best effort) |

## Disclosure

We appreciate responsible disclosure. After a fix is released, reporters will be acknowledged in the release notes (unless anonymity is requested).

> Note: this project is a research prototype with zero runtime dependencies; the primary focus is code reproducibility and data integrity rather than production-grade security boundaries.
