# Research Log — 研究日志

每次重要修改(代码/文档/实验/决策)必须在此追加一条记录。
条目格式(宪法第 7 条):

```text
## LOG-YYYY-MM-DD-<主题>

- 状态: 完成 / 进行中 / 放弃
- 关联: (假设/实验/问题编号, 可选)

### Problem
(要解决的问题, 一句话讲清楚)

### Hypothesis
(我们假设什么会怎样。没有假设的修改禁止进入日志——
 即使只是 bug 修复, 也要写"修复后检索延迟应回到预期区间")

### Change
(改了什么, 指向文件/模块)

### Experiment
(如何验证: 数据集、命令、指标)

### Result
(数字/事实, 可指向 research/results/ 的 JSON)

### Interpretation
(结果说明什么, 不说明什么; 是否更新假设状态)

### Next Step
(下一步, 或"无")
```

## 纪律

1. 只记录事实与解释, 不记录情绪。
2. 结果必须可复现(记录 config 与 seed)。
3. 假设被否定时, 在对应 hypotheses/ 文件中更新状态为 REFUTED 并写理由。
