## Problem

需要回答"第一块砖是否成立": Dynamic Net / Anchor / 渐进验证
在高歧义合成信息空间上, 是否真的比传统扁平检索更有效?
(宪法第 2 条: 不能被实验支持的概念不进核心架构。)

## Hypothesis

- H-001: Anchor 机制以显著更少的相似度计算达到可容忍的 Recall 损失。
- H-002: 多网渐进验证改进 F1 且提前识别未观测碎片。
- H-003: 多信号建图纯度高于纯语义建图。

## Change

- 实现合成事件语料(高歧义档位: 同事件 0.801 / 跨事件 0.530, 跨事件邻居
  占索引 39%)、三策略(A 传统 / B Anchor / C Multi-Net)、渐进验证器、
  证据图、指标与 Benchmark 脚本;
- 修复: 锚点检测从全库扫描改为索引候选池(否则效率主张自毁);
  验证器轮数与网数解耦; A 排除种子; 图分析纳入种子。

## Experiment

- 命令: `python scripts/run_benchmark.py --config configs/benchmark.small.json`
  (主模式) 与 `--truncate 0.6`(截断模式); k=10, 12 查询, seed=20260819。
- 原始数据: research/results/EXP-001-benchmark.small-k10-q12-*.json(两份)。

## Result

主模式: A F1=0.637 / B 0.512 / C 0.490; sim_calls A=95 / B=22 / C=1326;
MRR A=0.794 / B=0.933 / C=0.625; C 早停占比 0.75。
截断模式: A predR=0.614 / B 0.506 / C 0.554。
图纯度: 多信号 vs 纯语义差异 ≤ 0.013。

判定: H-001 FAIL(部分成立), H-002 FAIL(按原表述否定), H-003 NOT SUPPORTED。

## Interpretation

- 高歧义语料上, 扁平语义基线是质量基准; Dynamic Net 尚未证明更有效。
- 但存在真实的部分证据: Anchor 的 4.3× 效率提升与 MRR 反超;
  渐进验证早停机制有效。这些值得在修订假设后继续实验, 而不是废弃。
- H-003 是测量设计问题, 不是假设证伪: top-k 已被语义预筛,
  结构信号没有发挥空间。
