# H-004: 引用结构信号参与检索扩张——链恢复增益与事件聚类护栏（H-003 目标拆分）

- **状态**: UNVALIDATED（2026-08-19 注册；按 EXP-002 Next Step 第 3/4 条与
  `docs/engineering_plan.md` E2 Gate 要求，把 H-003 的合并表述拆分为两个
  可独立证伪的目标。H-003 自身维持既有判定：REFUTED(纯度口径) /
  PARTIAL(链恢复口径)，不因本拆分回改。）
- **关联问题**: RQ-3（早期识别增益）、RQ-4（结构一致性 vs 语义相似度）
- **关联实验**: EXP-005（预注册见 `research/experiments/EXP-005-cited-expansion.md`）
- **前置证据**: EXP-002 §7.3——引用边对**事后建图**无边际价值（跨事件引用
  目标不在语义预筛的 top-k 候选内）；全量层链连通率 0.940 vs 0.398 说明
  引用信号本身有效但**检索通道未兑现**。

## 假设（两个子假设，独立判定）

**H-004a（链恢复目标）**：在含因果链（mentions）的语料上，把引用边作为
检索扩张通道（B'/C' 策略变体，与语义半径扩张并列、独立计费），相比
同预算的纯语义扩张（B/C），显著提高**有序路径恢复率**——且该增益
不能被"纯语义 + 更大预算"（A 加大 k）复制。

**H-004b（事件聚类护栏）**：启用引用扩张后，事件聚类纯度的损失
≤ 10pp、F1@k 损失 ≤ 5pp（引用边跨事件桥接天然损害排他性聚类，
EXP-002 已示警——这是护栏而非增益主张）。

## 理由（为什么可能成立）

- EXP-002 全量层：+causal 链连通率 0.940（semantic-only 0.398）——
  引用信号对链恢复的真实效应存在，只是检索层通道没打开；
- 检索层 +causal 与 multi-signal 无差异的原因被定位为"候选集已按语义
  预筛"——把引用边放进**扩张**（影响候选生成）而非**事后建图**，
  是机制上对症的修改；
- 截断模式（RQ-3）：链上未观测碎片与种子的语义相似度不必然高，
  引用通道是语义通道之外唯一可到达它们的结构路径——早期识别
  （predictive recall）存在理论增益空间。

## 可证伪预测（在 BM-001 §7.3 因果链语料 + EXP-002 十格网格上）

1. B'/C' 的**有序路径恢复率**高于同策略无引用版本 ≥ +0.10，且配对
   随机化检验四闸门（p&lt;0.05 + CI 不含 0 + 跨 seed 一致 ≥80% +
   最小效应 ≥0.01，复用 `src/cognitive_os/stats.py`）全过；
2. 增益归因于引用信号而非预算：A 以 k×1.5 复跑不能达到同等
   路径恢复率（能则判 INCONCLUSIVE，增益归预算）；
3. 护栏：引用扩张启用时事件纯度损失 ≤ 10pp、F1@k 损失 ≤ 5pp。

## 证伪条件

- H-004a 主判定未达（路径恢复增益 &lt; +0.10 或统计闸门失败）→
  H-004a REFUTED：合成语料上引用信号无法经检索通道兑现，
  "结构信号参与检索"方向在当前语料规模证伪；
- A 大 k 复制了增益 → INCONCLUSIVE（预算效应，非信号效应）；
- 护栏爆线（纯度损失 &gt; 10pp 或 F1 损失 &gt; 5pp）→ H-004b REFUTED，
  引用扩张仅可作为"显式链恢复模式"启用，不得默认开启。

## 边界（宪法 §2/§9）

- mentions 是生成时设定的合成引用，真实世界引用需检测（噪声/漏检）——
  结论不外推到真实引用结构；
- 不优化延迟；引用通道成本（similarity_calls / index_lookups）独立入账；
- 有序路径恢复率需先有黄金值可手算的单元测试（E2 DoD），
  度量实现先于实验运行落盘。
